# Social Media Virality Predictor

A professional Streamlit application that predicts the virality probability of a social media post using machine learning. It accepts metrics such as views, likes, comments, and shares, then calculates a virality score between 0% and 100%.

## Project Overview

This project is designed as a practical, portfolio-ready ML dashboard for data analyst and business analyst applications. The current version uses a synthetic sample dataset so the app runs immediately in VS Code without requiring any external API or cloud service.

## Features

- Number of views, likes, comments, and shares input
- Safe handling for zero views to avoid division-by-zero errors
- Negative value validation
- Virality percentage prediction from 0 to 100
- Virality category classification
- Engagement rate calculation
- Progress bar and visual breakdown
- Feature importance chart generated by the trained model
- Clear warning that the synthetic dataset is demonstration-only

## Machine Learning Model

The model uses a RandomForestRegressor from scikit-learn.

### Why this model?

- Handles nonlinear relationships well
- Works effectively with tabular engagement metrics
- Provides feature importance, which is useful for business interpretation
- Performs reliably for a practical prediction dashboard

### Input features used

- views
- likes
- comments
- shares
- like_view_ratio
- comment_view_ratio
- share_view_ratio
- engagement_rate

### How the virality percentage is calculated

The model predicts a continuous score between 0 and 100 based on patterns in the provided features. The score is then mapped to a category:

- 0–20% = Low
- 21–40% = Moderate
- 41–60% = Good
- 61–80% = High
- 81–100% = Viral

## Dataset Notes

The project begins with a synthetic sample dataset to ensure it works immediately. This is only a demonstration dataset and not a real-world social media dataset. For higher-quality predictions, replace the generated CSV with your own historical post data.

### Minimum real dataset columns

Your real dataset should ideally include:

- post_id
- views
- likes
- comments
- shares
- published_date
- campaign_type
- virality_label or virality_score

If you want a stronger model, include additional metadata such as:

- content type
- posting time
- audience segment
- platform
- campaign objective

## How to Replace the Sample Data

1. Prepare a CSV file with historical post engagement metrics.
2. Add the same columns used by the model.
3. Replace the file at `data/social_media_data.csv`.
4. Run:

```powershell
python train_model.py
```

5. Restart the Streamlit app.

## Suggested Historical Data Size

For a useful predictive model, aim for at least 500 to 1,000 historical posts, and preferably more for stronger performance. The more diverse and representative your dataset is, the better the model will predict future viral behavior.
